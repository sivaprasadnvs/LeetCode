# LeetCode Solutions

A repository containing solutions to LeetCode problems across various difficulty levels and topics.

## Structure

This repository is organized as follows:

```
LeetCode/
├── Easy/
│   └── [Easy level problems]
├── Medium/
│   └── [Medium level problems]
├── Hard/
│   └── [Hard level problems]
└── README.md
```

## Problem Categories

Problems are sorted by difficulty level:
- **Easy**: Beginner-friendly problems
- **Medium**: Intermediate problems requiring more advanced techniques
- **Hard**: Advanced problems requiring sophisticated algorithms and data structures

## How to Use

1. Navigate to the appropriate difficulty folder
2. Each problem folder contains:
   - Solution code(s) in various languages (Python, Java, C++, etc.)
   - Problem description and explanation
   - Time and space complexity analysis

## Languages

Solutions are provided in:
- Python
- Java
- C++
- JavaScript
- Others as needed
