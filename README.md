# LeetCode JavaScript Solutions

A repository containing JavaScript solutions to LeetCode problems organized by difficulty level.

## Structure

This repository is organized as follows:

```
LeetCode/
├── Easy/
│   └── [Easy level problems]
├── Medium/
│   └── [Medium level problems]
├── Hard/
│   └── [Hard level problems]
├── TEMPLATE.md
├── .gitignore
└── README.md
```

## Problem Categories

Problems are sorted by difficulty level:
- **Easy**: Beginner-friendly problems to strengthen fundamentals
- **Medium**: Intermediate problems requiring intermediate JavaScript concepts
- **Hard**: Advanced problems requiring sophisticated algorithms and data structures

## How to Use

1. Navigate to the appropriate difficulty folder
2. Each problem file contains:
   - Problem description and constraints
   - Solution code in JavaScript
   - Time and space complexity analysis
   - Alternative approaches (if applicable)
3. Run solutions locally:
   ```bash
   node filename.js
   ```

## Problem Template

Use `TEMPLATE.md` as a reference when adding new problems to maintain consistency.

## Getting Started

- Check out [LeetCode](https://leetcode.com) for problem statements
- Test solutions locally before committing
- Include comments explaining the logic
- Document time and space complexity
